About this project

ChangeLens Analytics is a self-built data analytics portfolio project. It's a complete, working pipeline — not a mockup — covering data ingestion, cleaning and normalization, feature engineering (diffing), rule-based classification, a transparent scoring model, and an interactive multi-chart dashboard with filtering, search, and drill-down. The goal was to demonstrate the full analyst toolkit end-to-end on a problem that's genuinely useful: telling signal from noise in a stream of change events.

Read more about the design decisions on the Methodology page, or see common questions on the FAQ.

What this project demonstrates
  • End-to-end pipeline design: ingestion → cleaning → feature engineering → classification → scoring → visualization
  • Relational data modeling (SQLAlchemy + Alembic migrations) for a non-trivial domain
  • Building an explainable, auditable scoring model instead of reaching for a black-box one
  • A full test suite (unit + API-level) and CI, not just a working demo
  • A polished, accessible, responsive frontend built without a JS framework
